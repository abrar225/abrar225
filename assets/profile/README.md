# Profile artwork
Original point-cloud animation created for Abrar Akhunji's GitHub profile, inspired by https://abrarakhunji.com/.
Assets: light/dark 80-frame GIFs (6.4 seconds) and static PNG alternatives.
Fonts: Syne, Instrument Serif Italic and DM Mono, obtained from https://github.com/google/fonts (SIL Open Font License families). Fonts are rasterized in the artwork; no font binaries are bundled here.
Palette: dark #070B12 / #E8EEF6 / #79D0E0; light #F3F6F9 / #111820 / #106C7E.
No JavaScript, tracking, generated activity, or external rendering service is required by these assets.
