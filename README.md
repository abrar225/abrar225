## Building now

### FixoFlow — speak into the apps you already use

Offline voice dictation with local speech recognition, a personal dictionary, transcript history, and clipboard/paste integration.

- **Available:** English dictation in experimental preview.
- **Platforms:** macOS Apple Silicon; Windows x64 and Ubuntu X11 previews.
- **Current limits:** multilingual/Hinglish support is planned. Installation trust, recognition quality, shortcuts, and automatic paste vary by platform.

[Source](https://github.com/abrar225/FixoFlow) · [Website](https://fixoflow.tech) · [Download previews](https://github.com/abrar225/FixoFlow/releases) · [Contribute](https://github.com/abrar225/FixoFlow/blob/main/CONTRIBUTING.md)

### Rea API Studio — inspect APIs on your computer

A local HTTP workbench with collections, traffic capture, and inferred OpenAPI exports.

- **Available:** local request workflows, collection import/export, and a collection runner.
- **Current limits:** inferred contracts need review; this is not a complete Postman replacement.
- **Try it:** run the Node.js application locally. The hosted website is a static sample preview.

[Source and setup](https://github.com/abrar225/rea-api-studio) · [Sample website](https://abrar225.github.io/rea-api-studio/) · [Current readiness](https://github.com/abrar225/rea-api-studio/blob/main/docs/PLATFORM_READINESS.md)
